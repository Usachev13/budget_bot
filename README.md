# Бюджет: телеграм-бот и дашборд

Личный учёт денег: операции вносятся в телеграм текстом, голосом или файлом выписки,
дашборд показывает лимиты месяца, чистую позицию и прогресс по переезду.

## Как устроено

| Файл | Что делает |
|---|---|
| `config.py` | Все настройки: токены, ключ дашборда, лимит зарплаты, доли распределения ИП |
| `db.py` | База SQLite, справочник категорий, правила автокатегоризации, курсы валют |
| `parsing.py` | Разбор фраз («кофе 350»), голосовых через Groq Whisper, сложных фраз через модель |
| `bot.py` | Логика телеграм-бота: сообщения, кнопки, команды |
| `statements.py` | Импорт выписок: PDF Яндекс Банка и CSV любого банка |
| `import_sheet.py` | Загрузка истории из таблицы «Бюджет 2026» (xlsx) |
| `reports.py` | Все подсчёты: лимиты, остатки, чистая позиция, переезд |
| `app.py` | Flask: вебхук телеграма и дашборд |
| `templates/dashboard.html` | Сам дашборд |

## Логика денег

**Два кошелька.** Расходы из зарплаты имеют лимиты и в сумме дают 175 000 ₽ в месяц.
Расходы из ИП (налоги, переезд, праздники, инвестиции) лимитов не имеют и считаются отдельно.

**Три типа операций.** Расход, доход и перевод. Погашение карты, покупка шекелей и USDT,
пополнение копилки — это переводы, в расходы они не попадают.

**Чистая позиция** — все свои деньги минус задолженность по картам. Главный показатель на дашборде.

**Распределение денег ИП** — 60% переезд, 25% закрытие разрыва, 15% праздники и подарки.
Когда чистая позиция выходит в плюс, доля «закрытие разрыва» автоматически переключается на инвестиции.

## Запуск на PythonAnywhere (бесплатный тариф)

1. Создать бота у @BotFather, сохранить токен.
2. Зарегистрироваться на pythonanywhere.com, тариф Beginner.
3. В разделе **Web** создать приложение: Manual configuration → Python 3.11.
4. Загрузить файлы проекта в `/home/<логин>/budget/`.
5. В консоли Bash поставить зависимости:

   ```
   pip3.11 install --user flask requests pdfplumber openpyxl
   ```

6. В WSGI-файле приложения оставить:

   ```python
   import sys, os
   path = '/home/<логин>/budget'
   if path not in sys.path:
       sys.path.insert(0, path)
   os.environ['TELEGRAM_TOKEN'] = '…'
   os.environ['WEBHOOK_SECRET'] = 'длинная-случайная-строка'
   os.environ['DASHBOARD_KEY'] = 'пароль-для-дашборда'
   os.environ['OWNER_CHAT_ID'] = 'твой telegram id'
   os.environ['GROQ_API_KEY'] = '…'
   from app import app as application
   ```

7. Нажать Reload, затем открыть в браузере:
   `https://<логин>.pythonanywhere.com/set-webhook?key=<пароль-дашборда>` — это скажет телеграму, куда слать сообщения.
8. Дашборд: `https://<логин>.pythonanywhere.com/dashboard?key=<пароль-дашборда>`.

Свой telegram id можно узнать у бота @userinfobot.

## Загрузка истории

```
python3 import_sheet.py /путь/к/Бюджет2026.xlsx
```

Месяцы, которые уже загружены из банковских выписок, лучше пропустить, иначе суммы удвоятся:

```python
import import_sheet
import_sheet.run('Бюджет2026.xlsx', skip_months=('2026-09',))
```

Выписки просто присылаются боту файлом.

## Что важно помнить про бесплатный тариф

- 100 секунд процессора в сутки. Обычной переписки и пары выписок в день хватает с запасом.
- Бесплатное веб-приложение раз в три месяца нужно продлевать кнопкой в панели.
- Исходящие запросы разрешены только на сайты из белого списка PythonAnywhere.
  `api.telegram.org`, `api.groq.com` и `googleapis.com` в нём есть.
- База лежит в файле `budget.db` рядом с кодом. Раз в месяц стоит скачивать копию.

## Команды бота

| Команда | Что делает |
|---|---|
| просто текст | записывает операцию: «кофе 350», «+180000 комиссия» |
| голосовое | то же, но надиктовкой |
| файл PDF или CSV | загружает выписку |
| `/итоги` | лимиты месяца, доходы, чистая позиция, переезд |
| `/счета` | остатки по счетам |
| `/день` | траты за сегодня |
| `/разобрать` | присвоить категории операциям из выписок |
| `/отмена` | удалить последнюю запись |
